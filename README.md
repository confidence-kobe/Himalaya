# བོད་ཡིག་དཔར་རྡུལ་སྦྱོང་བརྡར། Himalaya 藏文打字练习

一个现代化的藏文打字练习网站，帮助用户提高藏文输入速度和准确率。

## ✨ 功能特点

- 🎯 **三种难度等级**：简单、中等、困难，适合不同水平的学习者
- 📊 **实时统计**：显示WPM（每分钟字符数）、准确率、进度和用时
- 🎨 **美观界面**：渐变色设计，响应式布局，支持移动设备
- ⚡ **即时反馈**：实时显示正确和错误的字符，当前位置高亮
- 🏆 **成绩总结**：练习完成后显示详细的统计信息
- ⌨️ **快捷键支持**：ESC重置，Ctrl+Enter开始
- 🌈 **动画效果**：流畅的界面动画和过渡效果

## 🚀 快速开始

### 在线使用

1. 直接在浏览器中打开 `index.html` 文件
2. 选择难度等级（简单/中等/困难）
3. 点击"开始练习"按钮
4. 在输入框中输入显示的藏文文本
5. 完成后查看统计结果

### 系统要求

- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 已安装藏文输入法（推荐使用系统自带的藏文输入法）
- 支持藏文字体（网站使用Google Fonts的Noto Serif Tibetan字体）

## 📝 使用说明

### 藏文输入法设置

**Windows:**
1. 设置 → 时间和语言 → 语言
2. 添加语言 → 选择"藏语"
3. 安装后可使用 Win+Space 切换输入法

**macOS:**
1. 系统偏好设置 → 键盘 → 输入法
2. 点击"+"添加藏文输入法
3. 使用 Ctrl+Space 切换输入法

**Linux:**
1. 安装 IBus 藏文输入法：`sudo apt-get install ibus-m17n m17n-db`
2. 在 IBus 设置中添加藏文输入法

### 练习技巧

1. **从简单开始**：如果您是初学者，建议从"简单"难度开始
2. **注重准确率**：先追求准确，速度会随着练习自然提高
3. **定期练习**：每天练习15-30分钟，效果最佳
4. **观察反馈**：注意红色标记的错误，学习正确的键位

## 📊 难度说明

- **简单**：常用问候语和短句，适合初学者
- **中等**：完整的句子，涉及日常对话和文化内容
- **困难**：长句和段落，包含复杂的词汇和语法结构

## 🎯 统计指标说明

- **WPM（Words Per Minute）**：每分钟输入的字符数，衡量打字速度
- **准确率**：正确输入字符占总输入字符的百分比
- **进度**：已输入字符数/总字符数
- **时间**：从开始输入到当前的用时

## 🛠️ 技术栈

- **HTML5**：语义化标签，无障碍访问
- **CSS3**：Flexbox/Grid布局，渐变和动画
- **原生JavaScript**：无框架依赖，轻量高效
- **Google Fonts**：Noto Serif Tibetan字体支持
